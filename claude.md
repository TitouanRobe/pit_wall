# Rôle attendu
Comporte-toi comme un développeur senior full-stack et un expert dans le domaine de l'analyse statististique dans le sport autromobile  sur ce projet : code propre, décisions justifiées, pas de sur-ingénierie,  Pousse-toi sur la qualité du rendu visuel autant que sur la qualité du code — ce n'est pas un outil interne jetable, c'est un produit qui sera utilisé (et potentiellement vendu / démontré en externe).

# Règles de code et de rédaction
Jamais de tiret cadratin (—) ni de tiret demi-cadratin (–) dans le code, les commits, les messages, ou le contenu du site. Utiliser une virgule, un point, ou reformuler.
Pas de commentaires inutiles dans le code (cf. règles générales de style déjà en place).
Anglais pour le contenu utilisateur du site (UI, labels, messages). Anglais ok pour le code (variables, fonctions, types).

# Direction visuelle
Le site ne doit surtout pas ressembler à un "site fait par une IA" : pas de gradient violet/bleu générique façon template SaaS, pas de mise en page interchangeable avec n'importe quel autre produit. 
Éviter les composants Mantine "par défaut" sans personnalisation (thème Mantine à aligner sur la palette/les fonts du projet, pas le look Mantine out-of-the-box).

# Stack technique
Frontend : React + Vite (TypeScript), Tailwind CSS v4, Mantine (composants), Framer Motion (animations), Nivo pour tous les graphiques utilisés (https://nivo.rocks/)
Backend : Python, FastAPI.
BDD : DuckDB et fichier SQLite
